# Sasi Scott | Contemporary Art & Music

This is a fully designed modern artist website for Sasi Scott. It is built purely with expressive, lightweight, vanilla HTML, CSS, and JS to run immediately in the browser without any build tools.

## Concept
The website is designed to feel:
- emotional, human, slightly chaotic, creative
- immersive like walking through a dark atmospheric contemporary exhibit space
- raw but premium

## Pages included (as single-page application views):
- **Home:** Cinematic hero section with glitch effects and floating polaroid aesthetics.
- **Music:** Immersive album exhibit cards.
- **Band:** A chaotic and personal layered scrapbook.
- **Journal:** A digital diary feel.
- **Tour:** Dates with a cinematic ticket format.
- **Gallery:** Visual archive via an abstract masonry layout.

## Running the project
1. Open the project folder in Visual Studio Code.
2. Double-click on `index.html` or open it with the "[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)" extension in VS Code to see it live.

*No setup required, no compilation needed.*
